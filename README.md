# Recipe App CLI

A command-line interface (CLI) application for exploring, searching, and managing recipes. Built with JavaScript, this project allows users to fetch recipes, view details, and navigate categories from the terminal.

## Features

* Fetch random recipes
* Search recipes by name or ingredients
* View detailed recipe information including time, rating, and ingredients
* Organized recipe categories
* CLI-friendly navigation

## Installation

1. Clone the repository:

```bash
git clone https://github.com/CSSKING09/Recipe_App_CLI.git
```

2. Navigate to the project folder:

```bash
cd Recipe_App_CLI
```

3. Install dependencies:

```bash
npm install
```

4. Run the app:

```bash
node index.js
```

## Usage

* Follow CLI prompts to browse recipes
* Select a recipe to view details
* Search recipes by keyword
